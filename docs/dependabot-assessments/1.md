# Dependabot alert 1

[CVE-2026-15830](https://github.com/advisories/GHSA-q238-5cxm-5c9h) reports Django GeoDjango vulnerable to denial of service through deeply nested geometry collections. The alert identifies `docs/requirements.txt`.

This alert concerns Django in the documentation requirements. Sphinx loads auditlog_tests.test_settings, which has no GeoDjango app or spatial database backend. No geometry parsing or spatial lookup calls were found. The assessment applies only to documentation generation; consuming applications need their own assessment. See [repository evidence](https://github.com/mathspace/django-auditlog-v3/blob/d32ffec4176db74e45bb0399f655afc3cd9984d9/auditlog_tests/test_settings.py).

Dismiss this specific alert as **vulnerable code is not used**. This does not assert that the package is patched. Reassess if dependencies or input paths change.

Keep the current documentation constraints: Django 5.2 requires Python 3.10 or later, while the existing docs environment uses Python 3.8.
